# Ref2VA 测试结果 —— 动画角色一致性主力路径

日期：2026-09-02　配置：768×1344 / 10.1s / 243 帧 / SageAttention 开启

## 速度

| 路径 | DiT | LoRA | 步数 | 秒/步 | 总耗时 |
|---|---|---|---|---|---|
| FL2VA（文生视频） | `fl2va_pruned_int8_convrot` | 8step turbo | 8 | 28.90 | 280 s（4.7 分钟，热） |
| Ref2VA（3 张参考图） | `ref2va_pruned_int8_convrot` | 4step turbo | 4 | 32.87 | 288 s（含冷加载） |
| **Ref2VA（1 张参考图）** | 同上 | 4step turbo | 4 | **30.29** | **174 s（2.9 分钟，热）** |

**Ref2VA + 4 步 turbo 是目前最快的生产路径：单条 10 秒竖屏 2.9 分钟。**

单步比 FL2VA 慢约 5%（参考图带来额外条件 token），但步数减半，净收益接近 2×。
参考图数量影响速度：3 张比 1 张慢约 8%（32.87 vs 30.29 秒/步）。

## 角色一致性：成立

用之前生成的狐狸视频抽帧作参考，让同一角色出现在完全不同的场景（秋日白天林间 → 夜晚河边萤火虫）。
保持住的特征：橙色毛+白胸白吻、深褐色耳尖与四肢、粗黑眉形、吻部雀斑、眼型、尾巴白尖、
线条粗细与 2D 手绘风格。**身份保真度足以支撑连续剧集的角色。**

## ⚠️ 两个必须知道的坑

### 坑 1：场景截图当参考图，会把参考场景一起拖进开头

用带背景的场景帧作参考时，视频**开头约 2.5 秒仍停留在参考图的环境**（白天秋林），
之后才逐渐过渡到提示词描述的夜景。`ref_image_size="max"` 锚定的不只是角色，是整张图。

**对策：用干净背景的角色设定图，不要用场景截图。**

### 坑 2：中性背景设定图解决了场景污染，但会丢构图

换成灰底角色设定图后，开场立刻就是正确的夜景河边 ✅，但**狐狸前 4 秒几乎不在画面里**
（只有左边缘一点脸），5 秒后才入镜。模型先把场景搭好，角色再"走进来"。

**对策：提示词必须显式写构图**，例如
"medium shot, the fox is centered in frame from the very first frame"。
设定图不提供空间位置线索，只提供身份线索，构图得靠文字补。

### 综合建议

参考图用**干净背景的角色设定图**（正/侧/背 + 表情，最多 9 张），
提示词里**同时写清身份、构图、动作、镜头、音频**。
参考图数量按需，不要贪多——每多一张都在加钱（时间）。

## 坑 3：ComfyUI 结果缓存

相同提示词 + 相同种子直接返回上次产物（15 秒"跑完"）。
换画面或测性能**必须换 seed**。

## 用法

```bash
cd /root/video-pipeline
# 参考图先放进 ComfyUI/input/
/root/miniconda3/bin/python driver/bench_r2v.py \
  --refs fox_sheet.png \
  --prompt "角色描述 + 构图 + 场景 + 动作 + 镜头 + 音频" \
  --seconds 10 --steps 4 --seed 42 --ref-size max \
  --prefix video/shot01
```

参数：`--ref-size max` 保身份保真度（慢，官方推荐）；`match` 更快但身份可能漂。
`ref_images` 在 API 里的键名是 `ref_images.ref_image_0/1/2...`（AUTOGROW 输入）。
